# AI 对话记录与提示词经验追加验收

日期：2026-10-17。

## 实现范围

- 用户消息靠右、AI 回复靠左；需求、追问、补充、成功结果、失败和取消按顺序保留在本次应用会话中，切换页面不清空，关闭应用不保存聊天记录。
- 成功提交清空输入框，底部固定输入区域；新回复跟随滚动，滚轮或滚动条查看历史时停止跟随，提供“回到最新”。
- 每条历史成功结果保留终端快照、APDU、完整报文、输入/编码参数、警告以及独立的复制和回填入口。
- 用户消息的“加入 698 提示词”打开可编辑预览，只有“确认追加”写入当前本地提示词文件。取消不保存，错误保留编辑内容；不自动上传共享目录。
- 追加经验保留原文，检查空白、空字符、单条 8192 字、文档 64 KiB、UTF-8、重复内容及符号链接；写入加锁，提交前重新核对文件内容，并使用 QSaveFile 原子替换。
- 当前生成和追问保持原提示词快照，下一次独立请求读取新增经验。是否符合业务意图由用户判断；不增加跨请求上下文或自动提炼规则。
