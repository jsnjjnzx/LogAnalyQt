# V4.0 毛玻璃界面验收

日期：2026-10-17。基于用户确认的日志解析、系统设置设计稿，采用深色毛玻璃材质，优先保持文字清晰。

## 覆盖范围

默认工作台的 15 个页面：日志解析、手动解析、差异对比、多窗口解析、智能组帧、实时监控、日志合并、预置报文、协议同步、系统设置、帮助与更新、功能说明、升级日志、检查更新、AI 助手。

共享控件覆盖按钮、输入框、下拉框、数值编辑器、复选框、开关、菜单和确认弹窗；组帧子编辑器、模型设置、终端管理、明文 APDU 与协议差异窗口也使用统一配色。

- 设置区使用半透明分组卡片、右侧开关和快捷键键帽；开关继续保存原有设置键。
- 日志与报文使用稳定的阅读底色。下拉菜单使用实色背景，避免后方文字透出。
- 保留浅色、跟随系统和减少透明度；减少透明度关闭背景效果并使用实色面板。
- 18px 主窗口圆角；最大化及全屏保持直角。保留原 Logo、导航含义及系统窗口操作。
- 本次未改协议编码/解析、AI 请求、凭据操作、SSH 信任、同步行为或数据迁移格式。系统文件选择器沿用系统界面，旧界面备用入口保留。

## 本机验证

环境：macOS arm64，Qt 6.11.1，Metal 原生渲染。截图与交互使用独立应用副本和临时 Application Support 目录；没有保存模型密钥、执行实际 AI 请求或连接公司设备。

- Debug 构建成功，23/23 组 CTest 回归通过。包括页面切换、真实解析、独立解析标签、重启恢复、损坏数据保护、凭据与同步边界、更新替换保护。
- QML 测试 54 项通过（含初始化/清理）：覆盖现有工作流及新增按钮键盘操作、禁用状态、数值验证、下拉选择、开关、主题切换和设置行布局。
- Python 发布工具、包校验、窗口与图标检查 28 项通过。
- 捕获全部 15 页深色、15 页浅色，以及 9 个页面的 1200×740 窄窗口，共 39 个基础场景；逐页无 QML 运行时警告。精修后重新捕获受影响页面。
- 原生操作检查设置开关、减少透明度、模型设置、终端管理弹窗、协议下拉框及 Escape 退出。真实鼠标切换减少透明度后，背景效果消失且设置卡片变为实色。

检查中修复了设置开关与标签重叠、菜单文字透出、禁用文字重复降低透明度、预置报文操作行高度不足，以及独立窗口的调色板继承。

本地截图位于本目录 `dark-*.png`、`light-*.png`、`compact-*.png`，运行记录为 `ctest.log`、`captures.log`、`final-captures.log`；生成图片与日志不纳入源代码提交。
