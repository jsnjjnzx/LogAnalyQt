# 个人配置统一管理验证

本记录对应发布前实现阶段；正式版本的构建和发布范围见 ../v4.2.0/README.md。

验证日期：2026-10-18，macOS arm64，本地 Qt 6.11.1 工具链。

## 已实现

- settings.json 统一存储个人设置；密码和设备状态独立。
- 启动只读扫描，用户确认后迁移；缺少任意旧文件直接跳过。
- 配置写入和回读、密码保存和最终回读、源文件一致性全部通过后，才清理确认清单中的旧文件。
- 未选来源的冲突不提交；选定后可在同一弹窗重试。
- 等待系统密码授权期间，新旧配置被外部修改时停止提交。
- 历史备份和构建目录不进入自动迁移与清理。手动选择旧目录只导入，原件保留，目录无需含 INI。
- 设置中的个人配置页面，配置导出、完整资源备份、分组恢复、旧目录导入及待应用任务取消。
- 恢复前留快照，启动时应用；支持中断回退，检测到外部编辑时停止覆盖。
- 预置报文 JSON 与共享目录 XML 双向交换，并拒绝状态过期的覆盖。

## 已验证

最终完整回归：**29/29 通过**，见 ctest.log。

配置专项：**130 条断言通过**，覆盖独立写入、损坏保护、缺文件、确认前只读、布尔值转换、密码失败/冲突/最终回读失败、授权期间源变化、配置写入失败、受保护目录、MQTT 目标身份绑定、模板与预置报文、目录导入、备份校验、分组恢复、中断恢复及外部编辑保护。

真实 QML 启动确认、取消不写入、确认后迁移和删除、冲突来源选择重试、新管理入口、MQTT 回环通信、解析工作区及保存失败保护均通过隔离程序副本验证。macOS 隐藏/最小化启动后的激活检查通过。
