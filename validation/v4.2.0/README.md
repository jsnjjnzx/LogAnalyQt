# v4.2.0 发布验证

发布日期：2026-10-18。

本版本将个人设置统一到 settings.json，增加系统设置中的管理入口、备份恢复和旧目录导入。迁移前必须确认；配置、密码及源文件一致性全部验证成功后，才能删除清单中的对应旧文件。历史备份和构建目录不自动处理。

发布前已经过用户实际体验独立 macOS 测试版。该测试版的合成数据、独立测试目录、测试凭据域和启动器不作为正式安装包入口。

## 本地检查

- 配置专项 130 条断言通过，覆盖缺文件、取消、冲突选择、授权等待中的文件变化、凭据失败、删除条件、备份校验、恢复中断和外部编辑保护。
- 4.2.0 版本号下的本地构建成功，完整回归 29/29 通过；发布工具 26 项模拟测试通过。
- Windows 符号链接样例仅在支持 Unix symlink 的平台执行；Windows 的 QFile::link 是快捷方式，不能伪作 symlink 验证。
- 自动升级测试在 macOS 标准数据目录种入用户提示词，避免依赖旧安装目录的复制行为。

## 云端发布检查

GitHub Actions 构建并测试 Windows x64 与 macOS arm64，分别检查独立安装包、校验值和无开发环境依赖的启动。版本标签工作流仅在两端成功后发布完整 Release，再从公开附件执行更新、替换和重启验证。

## 边界

云端 Windows 检查不代表公司设备或 Windows 实机验收。macOS 使用 ad-hoc 签名，未经 Apple 公证。密码和私钥不随普通配置备份导出；真实密码迁移仍在使用者首次确认时实际保存并验证，失败不得清理原件。

发布过程不替换本机安装版，不对真实旧配置执行迁移。
