# 新工作台迁移验收记录

日期：2026-10-14。

## 已实现

新版作为默认入口；新代码在 `qml/Next/`，原 `qml/Main.qml` 及原功能窗口、组帧编辑器均保留。
`--legacy-ui` 加载原模块，两个入口复用现有业务引擎、协议、预置配置。
新版窗口尺寸与外观使用 `next/` 配置键，避免覆盖旧版窗口布局。

| 页面或界面 | 迁移结果 |
| --- | --- |
| 日志解析 | 文件/文件夹选择、编码、搜索、正则、全局预览、拖放、粘贴、行号、收发标记着色、字段联动 |
| 手动解析 | 协议选择、预置选择、输入、解析、列宽调整/锁定、698 地址修改 |
| 差异对比 | 双输入、字段差异、同步滚动、上一处/下一处差异、多帧分隔 |
| 双窗口解析 | 两个解析面板，关闭差异标注 |
| 智能组帧 | 698 全部既有服务编辑器、OAD/OMD、RSD/RCSD、APP 请求/响应/事件、消息头、校验、复制、回填 |
| 实时监控 | SSH 连接、编码、缓冲、重连、终端、搜索、报文解析、命令历史/自定义命令 |
| 日志合并 | 多文件选择、顺序调整、输出位置、时间排序合并与进度 |
| 预置报文 | 分类、添加、编辑、删除、版本/日期管理 |
| 协议同步 | 连接配置、文件状态、下载/上传/同步、结果、XML 差异窗口 |
| 外观 | 深浅色、跟随系统、减少透明度、配置持久化 |
| 帮助与更新 | 内嵌功能说明/升级日志、检查更新、原下载/校验/安装状态机 |
| 辅助界面 | 明文 APDU 检查、组帧校验、OAD 选择、确认与安全提示 |

切换工作区不销毁页面，因此保留编辑状态和终端会话；关闭应用时断开终端。
瞬时的文件选择、确认、校验等继续使用弹窗。

## 控件修复

用户指出的加减按钮挤压数字问题已通过共用 `CompactSpinBox.qml` 修复。
25 处数值控件统一固定按钮宽度，按最大数值计算中间输入区最小宽度，保留
直接输入、键盘、加减、边界和禁用行为。已移除未使用的旧数值控件定义。
OAD 窄面板自动分行，SSH 参数和动作分组为三行，组帧选择器和动作分行。

迁移联调同时修复：

- APP 组帧回填误将协议编号用作解析面板编号的问题。
- 过滤结果回写原始文本导致清空过滤不能恢复的问题。
- 无效正则不再替换日志正文；继续使用 Qt 的正则语法，支持 `(?i)` 等 PCRE 表达式。
- macOS 文件夹 URL 不再去掉根路径 `/`。
- 698 第二面板成功解析后未返回成功、因而丢失多帧分隔的问题。
- 组帧校验弹窗在 Bound 模式下缺少模型角色声明、显示空白的问题。
- 若干旧窗口变为页面后的布局、动画作用域、空字符串/颜色绑定问题。
- 645 XML 调试输出使用无目标 QTextStream 造成重复警告的问题。

## 已验证

1. macOS Debug 构建：隔离验证目录 `build/ui-migration/`，正常构建目录 `build/macos-debug/`。
2. `ctest --test-dir build/ui-migration --output-on-failure`：12 组全部通过，日志在 `tests.log`。
   新增 UI/真实引擎检查从临时复制的应用启动，不操作已有便携数据。
   覆盖 14 个页面路由、Unicode/空格文件路径、日志过滤恢复、无效正则、全局预览、
   104 与差异、698 组帧与第二面板多帧、APP 回填、南网解析、APDU 窗口、预置增删改、
   实际日志合并顺序及打包帮助文档。
3. Qt Quick 数值控件测试：4 项交互测试通过（另有初始化和清理），日志在 `numeric-controls-tests.log`。
   覆盖输入区不被遮挡、直接输入、加减、上下限、禁用状态。
4. 实际窗口操作：
   - 服务序号输入 12，698 APDU 中生成 `0C`，完整封装后可回填手动解析。
   - APP 心跳请求生成完整消息、校验、回填；协议正确切换为应用层消息。
   - 原生文件选择器打开专用 `log-input.txt`；选择报文后自动识别 IEC 104。
5. 页面截图与控件对照：见同目录 PNG/JPG 和 `design-qa.md`。

## 启动与回退

- 新版：`scripts/run_new_ui.command`。
- 旧版：先关闭当前应用，再运行 `scripts/run_legacy_ui.command`；或传入 `--legacy-ui`。
- 测试宏仅在 `LOGANALYQT_BUILD_PROTOCOL_TESTS=ON` 时启用，发布配置默认不包含 UI 测试入口。

数值控件单独复查命令：

```sh
QT_QUICK_CONTROLS_STYLE=Basic /opt/homebrew/opt/qtdeclarative/bin/qmltestrunner \
  -input tests/qml-next -platform offscreen
```
