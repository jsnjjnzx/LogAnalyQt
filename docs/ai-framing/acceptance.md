## 2. 标准版本与独立正确例帧

官方全国标准信息公共服务平台在本次查阅时列出：

- [DL/T 698.45—2026](https://std.samr.gov.cn/hb/search/stdHBDetailed?id=5B957AE5C657432CE06397BE0A0A659F)：2026-06-26 发布、2026-12-26 实施，全部代替 2017 版。

这两页只能证明版次及发布日期/实施日期，未取得并核对其协议字节定义或附录例帧。**本任务对接现有工程的范围以当前项目实际加载字典与现有协议行为为基准，不擅自升级 2026 版；XML 的 v1.0.1 不等于标准年号，现有协议版次来源尚未确证。** 后续如需声明某标准版次完整兼容，应另行取得适用标准和字节依据，不能扩大本轮为协议升级。

本次检查的 `tests/`、`tests/fixtures/`、相关 `docs/` 和 `validation/` 中，未找到带可核验 698 标准页码/条款或独立设备来源的完整 golden 帧。现有 CSG fixture 和南网技术规范属于另一规约，不能挪作 698 正确性依据。不得从网页零散例子、模型回答或编码器本次输出反推“正确期望值”。

后续 golden 集每条至少登记：案例 ID、标准版次/厂商版本、文档标题和条款/页码或原始采集文件、已知输入语义、完整帧或明确的 APDU 边界、期望十六进制、独立校验人、适用条件。设备采集需标明是请求还是经设备确认有效的交互，单向抓包不自动代表正确。

可接受的独立依据依次为：已核对的适用标准/厂商正式示例、用户提供且可追溯的真实正确交互、来源及版本明确且与本编码器无共享实现的独立工具。手工按标准逐字段推导可以作为复核，但应保存推导与独立 CRC 计算过程，不能只粘贴最终结果。

每个声明支持的服务必须有独立 APDU/完整帧或逐字段标准推导依据。完整帧基准还须独立核对长度、控制域、地址字节顺序、HCS/FCS、APDU 起止和结束符。缺材料的服务继续做本地逻辑验证，但保持“独立依据待验证”，不能因此缩成对时专用能力。

## 4. 数据与结构覆盖矩阵

类型名以 `Prot698Def.h`、当前 XML 原始值和编码入口共同核对。下表是覆盖要求，不是现有实现通过清单。没有出现在 XML 的已声明类型也要有独立单元输入；XML 中含糊/空定义不能靠 AI 猜。

| ID | 类型/结构 | 最小正例与边界 | 必须拒绝或澄清 |
| --- | --- | --- | --- |
| D01 | Null/NULL/null | 显式 null，带标签与内部无标签边界 | 未知类型、缺失值不能当 null；null 不等于空列表或空串 |
| D02 | Bool | true、false | 字符串假值、任意非零数字的无约定隐式转换 |
| D03 | Integer、Long、DoubleLong、Long64 | 各自有符号 min/0/max | 越界、非整数、负数精度丢失、无效字符串 |
| D04 | Unsigned、LongUnsigned、DoubleLongUnsigned、Long64Unsigned、Enum | 0/max；枚举字典项；64 位按无损合同传输 | 负数、溢出、未知枚举、超过 JSON 安全整数后被浮点舍入 |
| D05 | Float32、Float64 | 0、正负有限值、带明确标准依据的端序 | NaN/Infinity、超范围、主机内存序直接当线序 |
| D06 | BitString | 0/1、非整字节长度、空值约定、长度编码边界 | 任何非 0/1 字符、长度与有效位不符 |
| D07 | OctetString、MAC、RN、Checksum | 合法 HEX、空串约定、127/128/255/256 等长度边界 | 奇数位 HEX、非法字符、定义固定长度不符 |
| D08 | VisibleString、Utf8String | ASCII、UTF-8 中文、按字节计算长度 | 不能表示的字符静默变问号；长度与编码不符 |
| D09 | DateTime、Date、Time、DateTimeS | 闰日、年月日时分秒边界；日期时间扩展字段；标准定义的通配/无效标记另测 | 缺字段、无效日历日期、非法毫秒/星期；未声明时区的相对时间需澄清 |
| D10 | OI、OAD、OMD | 固定字节长度、属性/方法/index/mode 各边界 | 错长、非 HEX、无定义属性/方法、权限与业务不匹配 |
| D11 | ROAD、CSD、RCSD | ROAD 的主 OAD + 关联 OAD 列表；CSD choice 0/1；RCSD 多列 | 将 ROAD 当固定 4 字节 OAD、未知 choice、缺关联项/数量不符 |
| D12 | TI、TSA、ScalerUnit | 单位+值、地址指示与长度、scaler 正负及 unit；字节序独立复核 | 非法单位、范围/长度不符；物理值与原始整数混用 |
| D13 | RSD | 当前 Schema 分支 0–11，各分支完整字段；递归选择器 | 省略子字段、未知分支、循环/深度或数量超限；不能仅测试 RSD=00 |
| D14 | MS | 当前 Schema 分支 0–9，地址/序号/区域等所需集合 | 分支与载荷不符、空/越界集合；范围和成员类型不符 |
| D15 | Region、SID、SID_MAC、COMDCB、VQDS | 按适用标准拆分子字段、组合和边界 | 仅透传 HEX 不足以宣称“完整结构化支持”；未知字段明示缺口 |
| D16 | Array | 空/单/多项、嵌套数组、数组含结构、元素选择类型；数量上限及长度编码规则 | 错误元素类型、超限、缺元素定义；禁止默取第一个 option |
| D17 | Structure | 每字段类型与顺序、结构含数组/结构/动态 Data | 少字段、多字段、字段错位、缺值补零、未知字段静默忽略 |
| D18 | Data/data/DATA | 显式带类型的递归值，适用分支均可描述；与 XML 已知类型交叉核对 | 当成 Null、由模型自由输出整段原始字节、缺类型时猜测 |
| D19 | XML option、TypeOption、Selected、空 Type | 0000 属性 2 等 option 候选按实际元数据保留；大小写/连字符统一 | TypeOption/Selected 丢失、空 Type 当 Null、按名称臆测候选 |
| D20 | 服务复合结构 | PIID/PIID-ACD、timeTag、setItem/actionItem、普通/记录结果、代理目标/结果、GET_NEXT choice | 必填缺失、非法 choice、Data 与 DAR 同时出现或都缺、hasData=true 却缺值 |

重复 OI/属性按用户确认的当前 last-wins 行为加载，同时向用户提示重复；不因存在重复就自动阻止全部组帧。必须测试覆盖前后版本的实际加载结果与工具查询一致，不能把 XML Item 总数当唯一对象数量。

针对 raw HEX，验收区分“明确允许的有界原始数据输入”与“通用结构化支持”：前者也必须校验长度和适用类型，不能以一段任意 HEX 绕过对象权限、分支和必填值校验。模型输出直接指定最终 APDU/CRC/服务器地址不视为合法确定性工具结果。
