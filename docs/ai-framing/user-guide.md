# 698 自然语言组帧使用说明

本功能在新版工作台的“AI 助手”中使用：描述需求，查询当前加载的本地 698 对象定义，由本地程序校验参数、生成 APDU 和完整报文，再复制或回填人工解析。对时、设地址是通用流程的测试场景，没有专用业务捷径。

当前交付已完成本地构建和自动回归，并在 macOS 原生窗口通过真实 DeepSeek 的配置保存与重启恢复、读取时间、设置时间、多对象读取、缺参澄清后继续，以及复制回填验证。具体需求与报文见 [真实联调记录](../../validation/ai-framing/live-deepseek.md)。后台凭据版已原生复测取消状态保持和保存完成，最终取消保护版 `1ef45ab` 的 L08 新生成也已通过；未强制原生重现长授权等待，Windows 实机仍待验证。最新证据及范围见 [验收记录](acceptance.md)。

## 1. 配置大模型接入

1. 打开“系统设置 → 大模型接入”；也可以在 AI 助手右上角点击“模型设置”。
2. 填写服务根地址，例如页面提供的 DeepSeek 地址。必须使用 HTTPS，允许服务根地址或 `/v1` 根地址，不填写 `/chat/completions`。填入你账号实际可用的模型 ID。
3. 在软件的 API Key 密码框中输入密钥。需求和查询到的必要定义会发往所配置的模型服务；不要把密钥写进需求框或发送到聊天中。
4. 点击“保存设置”后先显示处理中，这只表示操作已受理。等待“设置操作完成”等最终结果；只有实际成功才清空密钥输入，页面以圆点和“已保存于……地址”表示保存状态，不回显密钥。
5. 点击“测试连接”。它会发送一次小型工具请求，可能产生少量计费；只有服务、鉴权、模型及工具响应校验通过才显示成功。测试期间可以点击“取消连接测试”。

**“测试连接”不会保存当前输入。** 即使测试成功，也要单独点击“保存设置”。连接成功只证明这一次小型工具请求可用，不证明完整业务生成成功。

同一已保存服务地址下，保存时 API Key 留空可保留原密钥。更换服务地址时需要重新提供该服务的密钥；程序不会把旧地址的密钥自动送往新地址。清除已保存密钥使用“清除已保存密钥”按钮。生成或澄清进行中需要先取消，再修改模型配置。

凭据读取、状态检查、保存和清除在后台串行执行。看到“核验凭据”或“等待系统凭据”不表示未配置；如系统出现钥匙串授权框，请由你按系统正常流程完成或拒绝，应用不会代填系统密码。等待期间不要重复提交凭据操作，界面会保持处理中。

凭据等待超过约 30 秒时，本次读取对应的生成或连接测试会失效，但系统调用可能仍在等待；取消逻辑请求不会强行终止系统调用。保存/清除也不会因为等待通知而被宣称成功或撤销，必须等最终完成结果。实际系统调用返回前，新的凭据操作仍会被阻止。测试连接的开始、完成、取消不会覆盖尚未保存的服务地址和模型草稿。

普通模型配置保存在应用便携目录的 `LogAnalyQt.ini`；macOS 的便携目录是 `.app` 所在目录。API Key 使用系统安全存储，macOS 为钥匙串、Windows 为凭据管理器，不写入这个 INI，也不随便携目录一起复制。当前平台安全存储不可用时会显示不可用，不降级为明文保存。

保存后应从**同一程序位置**退出并重新打开，核对服务地址、模型和密钥保存状态。本次真实验收已确认：在最新窗口保存后，同一应用重启显示已配置并能实际生成；提示词修正版更新后配置仍恢复，无需重新输入 Key。不同构建副本或临时验收副本可能使用不同的便携配置目录；此前一次未配置报告的原因没有证实，不据后续复验倒推其原因。

## 2. 填写当前终端

AI 助手首次打开时，终端地址为空，需要填写真实目标。

- 地址按设备资料中的显示顺序输入，长度为 2–32 位、偶数位十六进制，即 1–16 字节。无需手动翻转，不填写 `0x`、冒号或地址内部空格。
- 按目标资料选择单地址、通配地址、组地址或广播地址；逻辑地址当前支持 0、1。“高级参数”中可以设置客户机地址 CA，范围为 0–255。
- “管理终端”可修改名称、新增或删除终端。终端有稳定的会话内标识，切换时保留本次打开期间的编辑内容。

终端列表和当前选中项**只保留在本次会话中**，关闭应用后需要重新填写。本轮只有模型接入配置及安全凭据需要持久化。

提交时会冻结终端地址、地址类型、逻辑地址、CA、提交时间及本次协议定义。后续切换或编辑侧栏不会改变在途请求。需要更换目标时，先取消，再使用新终端提交；在需求里写另一地址不能覆盖外层目标。

## 3. 描述需求并处理澄清

在“自然语言组帧”中输入操作，然后点击“生成报文”。建议描述动作、对象、具体值，以及需要的单位和时间语义，例如：

- `读取当前终端的日期时间。`
- `读取 OI 4000 的属性 2，索引 0。`
- `把当前终端时间设置为 2026-10-14 21:30:00，按终端本地时间理解。`（这是日期写法示例，不是自动采用的当前时间。）

模型会通过本地目录查询服务、对象和输入定义，再提交结构化参数。缺值、同名对象、读写歧义、单位或时间语义不明确时，页面显示具体澄清问题。在同一输入框补充信息，点击“补充并继续”；续问仍使用原请求及原终端快照。

遇到单位或大整数应提供明确、精确的文本值，避免只写“差不多”“按默认值”。本地程序校验单位、倍率、整数范围和日期，不会将无法精确转换的物理值截断后输出。设置对象的通信地址属于业务参数，与本次报文外层发送目标是两个字段。

代理读取需要明确每个内层目标地址及必要参数，本地程序生成对应地址编码。记录结果可按普通 OAD 列的定义组织二维行数据，不需要模型拼接整行 HEX。最终可用范围取决于当前加载的对象定义和服务分支；对象不存在或定义含糊时，会返回具体不足。

## 4. 审阅、复制与回填

成功结果显示“已构建 · 本地验证”，并给出本次结果绑定的终端、服务说明、APDU 和完整报文。即使此时侧栏已选中另一个终端，结果仍显示原目标。

点击“查看输入参数 / 编码参数”可以对照：

- **输入参数**：本次原始结构化参数及运输层默认，保留 physical/raw、单位等信息。
- **编码参数**：本地校验和精确转换后的线值。64 位整数按 C++ 生成的精确文本展示，不经过页面浮点数重新序列化。

检查具体参数后，点击“复制完整报文”，或点击“回填手动解析”。回填会进入已有的手动解析工作台，用本地生成的完整报文进行解析。重复对象或成员定义会显示提示和计数，仍按已确认的最后生效项工作；`Size` 只作参考，实际长度按数据类型与服务结构校验。

结果没有发送到终端。“已构建 · 本地验证”不代表设备接受、执行成功或正式投用。

## 5. 取消和失败处理

- 生成、准备读取凭据或澄清时可点击“取消本次请求”。取消后的迟到结果不能继续本次构建或覆盖当前结果；系统凭据调用若仍未返回，会继续显示等待并阻止重复提交。若点击到达时请求已经成功，结果保持显示，不会被迟到取消隐藏。
- 切换工作台隐藏页面时，任务可以继续；需要停止时主动点击取消。销毁页面只取消由该页持有且请求 ID 匹配的活动任务，避免误取消其他请求。
- 网络、鉴权、额度、限流、模型响应格式、超时或本地参数校验失败会显示对应提示，不产生可成功回填的报文。
- 模型输出的文字不是最终 HEX。只有本地校验和构建成功的结果能进入复制、回填流程。

保存失败时，页面保留服务地址、模型和密钥草稿以便重试，不显示虚假的保存成功。清除密钥成功只清空 Key 输入，不覆盖尚未保存的地址/模型草稿。若另一个运行副本显示未配置，请核对程序位置和最终保存结果；测试连接本身仍不保存当前输入。本次真实重启恢复、后台版原生取消状态保持已有记录，长时间授权等待及迟到/析构的完整覆盖另由阻塞凭据仓库自动测试提供，不混作实机强制重现。

## 7. 支持范围与明确限制

服务目录保留 18 项：读取、设置、执行的单项/列表，读取记录、下一块、代理读取，以及这些服务的对应响应。它们已有本地基础正例、错误参数及能力状态测试；这不等于每个对象、每个分支均有独立标准或设备验证。

| 范围 | 当前边界 |
| --- | --- |
| 对象和数值 | 使用当前加载的工程字典；支持通用结构、数组、明确选择的 option、typed Data、整数/枚举/日期等已实现类型，单位和倍率按定义精确处理 |
| 代理目标 | AI 使用显示地址、地址类型和逻辑地址结构，本地生成 TSA；其他 Data 内地址字段仍遵守各自公开的输入形状 |
| 记录结果 | 普通 OAD 列支持结构化 `rows`；行列数量、每个值的类型、单位及范围由本地检查 |
| ROAD | 非空 ROAD 记录 cell 的实际容器和排列仍缺目标证据，AI 返回局部“不支持”；相关请求、DAR、空记录和旧人工明确字节路径保留 |
| 尚未开放的定义 | 空/未知类型、未知操作权限、非零 AI 属性索引/方法模式、未结构化 opaque/MS 原始分支、扩展逻辑地址、分帧和加扰等，按具体路径报不足，不猜补 |
| 平台 | 当前正式自动回归在 macOS 完成；Windows 有实现路径，但尚未做 Windows 实机原生和凭据验收 |
| 外部验收 | 已通过所登记的真实生成、澄清继续、复制回填、配置恢复及后台版取消状态保持/快速保存；最终取消保护版L08新生成也已通过，长授权等待未算作原生强制复现。有限用例不证明所有服务/对象或设备接受，设备发送不在本轮范围 |
| 其他功能 | “报文解释”明确尚未实现，不发送解释请求；原有人工组帧、解析和预置工具保留；本轮不交付 SDK |

采用现有工程字典和协议行为，不擅自升级标准，也不宣称某个标准年号的完整认证。独立来源及协议覆盖细节见 [能力清单](capabilities.md)、[来源登记](../../tests/prot698_sources.md) 和 [验收记录](acceptance.md)。

## 8. 本机启动入口

本机稳定构建位于项目目录的 `build/macos-debug/appLogAnalyQt.app`；需要重新构建启动时使用 `scripts/run_new_ui.command`。这是当前macOS工作区构建，不是已验收的Windows安装包或对外发布包。

`validation/ai-framing/live-preview-path.txt` 指向的 `/private/tmp` 副本仅用于隔离验收，不作为长期安装位置。普通配置跟随 `.app` 同级目录，Key仍保存在系统凭据中；切换程序位置后应核对服务地址、模型及保存状态，不把临时副本的配置位置误认为其他构建的配置位置。


## 9. 编辑与共享同步提示词

默认提示词现在位于便携目录的 `prompts/ai_698_framing.md`，与 `protocol_xml` 平级。macOS 放在 `.app` 外侧；Windows 放在程序旁边。首次运行或文件缺失时释放内置默认文件；已有文件不会被启动、升级或构建时覆盖。

在“系统设置 → 大模型接入 → AI 组帧提示词”查看实际文件路径，点击“打开提示词文件夹”，使用普通文本编辑器保存为 UTF-8。每次提交新的组帧任务时自动读取；进行中的生成和澄清继续使用提交时的版本。文件为空、编码错误、含空字符、超过 64 KiB 或无法读取时会报告错误，停止该次请求，不悄悄使用其他版本。终端、PIID、时间和定义版本仍由程序添加，本地参数校验保持生效。

共享同步使用原同步页面：

1. 打开“协议同步”，将“同步内容”切换为“AI 提示词”。
2. 填写保存 `ai_698_framing.md` 的共享目录。初始地址取 XML 共享目录的同级 `prompts`，之后独立保存，可自行修改。共享上的目录需已存在且当前账号有访问权限。
3. 点击“连接”，按原有平台方式完成共享认证；macOS 使用 Finder 系统登录。
4. 查看文件状态和“差异”，选择单文件“同步”或“一键同步”；本地编辑后可点击“刷新状态”。下载成功后从下一次组帧任务生效。

默认文件释放与共享同步互相独立：本地文件不存在时才释放，存在时不覆盖或改写文件时间。启动、释放默认文件和刷新状态均不会自动上传或下载；只有用户手动点击“同步”或“一键同步”才执行。所有提示词采用相同规则，不对默认文件设置特殊下载优先级：内容相同即视为一致，不同内容按修改时间选择上传或下载。同时间的不同内容会标记冲突，需查看差异并保存希望保留的版本后刷新。客户端会在覆盖前检查双方内容是否仍与状态列表一致，变化时拒绝覆盖并要求刷新。非法提示词不会替换另一端的原文件，写入沿用原子替换。共享文件时间取决于双方系统时钟，批量同步前应核对方向。

此改动在 macOS 完整构建成功，整合回归 21/21 通过（31.93 秒），包含控制器 338 项检查、设置及原界面 47 项 QML 检查、同步和终端两套界面 22 项 QML 检查，以及提示词文件释放与重启保留。证据见 [构建记录](../../validation/prompt-files/build.log)、[回归结果](../../validation/prompt-files/tests.log) 与 [详细检查](../../validation/prompt-files/detailed-tests.log)。使用隔离文件、模拟共享挂载和模拟模型请求，不代表公司共享上的真实写入验收、新的真实模型效果验收或 Windows 实机验收。
