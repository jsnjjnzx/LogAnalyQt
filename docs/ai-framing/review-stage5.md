## 已检查的行为

控制器冻结终端、定义、PIID、提交时间和模型配置；业务工具不能改外层目标。HTTP、工具、澄清和总运行时间均有预算，澄清暂停计时但不重置预算。取消先失效活动状态，再取消网络；回调核对本地 requestId 与状态。多工具按原序续接 tool_call_id，build 必须最多一次且为本批最后一项。成功仅来自本地 build_frame，结果再核对 requestId、definitionId、终端和服务；模型普通文本只能进入澄清，不能直接成为成功帧。

保存设置与生成/澄清/连接测试互斥，清 key 会先取消活动流程。坏 envelope、未知工具和坏 JSON 按已冻结合同安全终止，合法调用的业务参数错误才返回模型有限修正。
