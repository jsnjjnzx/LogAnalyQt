## 冻结安全边界

1. 系统安全存储全部后台串行调用，getters只读缓存；不绕过OS权限，不强杀线程。
2. SSH密码身份为host+port+username；主机信任身份为host+port，换key算法不能当首次连接。首次确认绑定requestId和指纹，只有当前明确同意才进入密码认证。取消或迟到确认无效，key变化禁止自动重连。
3. 旧明文迁移：读取快照、检查目标冲突、写并回读一致、重查INI原字段未变、删除并检查sync。失败/冲突不删除原字段、不覆盖其他凭据；不制作明文备份。
4. SMB输入不得包含凭据/query/fragment/逃逸路径。系统接手URL不等于已挂载；核对host/share来源，不猜/Volumes名称。取消不杀Finder、不卸载用户卷。
5. 已受理存储/同步写事务不能因超时或关闭页面虚报撤销；未提交的临时写可清理，失败保留远端旧文件。
6. 首批测试使用假密码、随机钥匙串项、本地隔离服务与文件；不读取用户真实凭据或擅自连接公司设备/共享。不以本地替身通过冒充公司环境验收。
