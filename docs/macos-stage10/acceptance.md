## 操作与交付边界

首次 SSH 指纹须独立核对；已知主机密钥变化必须拒绝并由人工可信处理。密码只有明确“保存密码”才新增持久保存；旧配置迁移另按已批准规则执行。空密码输入只可复用绑定当前目标的已存值。冲突或失败时保留恢复材料，不自动猜测目标或覆盖其他密码。

系统授权等待不锁住界面；后台事务 pending、Finder 接手和连接受理均不等于成功。取消不能保证撤销已经完成的系统存储或已经 commit 的文件写入；已提交下载仍须重载。目录不可写、挂载歧义、权限/网络或差异读取错误必须保留明确失败状态。

本阶段不扩展协议、不新增历史记录或终端持久化功能，不把自动测试、原生随机凭据检查或本机 SSH peer 等同公司生产验收。使用步骤见 [Mac 使用说明](user-guide.md)，执行及退出状态以 [执行记录](execution.md) 和 [独立审核](review-stage10.md) 的最终整合更新为准。
